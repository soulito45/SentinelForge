# SentinelForge

## External Attack Surface Intelligence & Risk Monitoring Platform

SentinelForge is a cybersecurity platform designed to discover, inventory, assess, and monitor an organization's authorized external attack surface.

It correlates domains, subdomains, IP addresses, ports, services, technologies, and security findings into a unified asset inventory.

### Core Capabilities

- External asset discovery
- DNS and subdomain enumeration
- Port and service discovery
- HTTP/HTTPS probing
- Technology identification
- Vulnerability detection
- Risk prioritization
- Asset history
- Attack surface change detection
- Security monitoring dashboard

### Technology Stack

- Python
- FastAPI
- PostgreSQL
- React / Next.js
- Nmap
- Nuclei
- HTTPX
- Subfinder
- Docker
